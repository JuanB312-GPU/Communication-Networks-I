# Entregas de Talleres - Redes de Comunicaciones I

Este repositorio contiene las entregas de los talleres realizados para la asignatura **Redes de Comunicaciones I**. Cada taller aborda conceptos y prácticas sobre el funcionamiento de las redes de comunicación, protocolos, y simulaciones de red.

## Estructura de los Talleres

Cada taller tiene su propia carpeta dentro del repositorio, donde se incluyen los siguientes elementos:

- **Código fuente**: Scripts, configuraciones o simulaciones necesarias para cada taller (cuando aplique).
- **Documentación**: Un archivo `informe.pdf` que incluye el análisis, resultados, y conclusiones del taller.
- **Archivos adicionales**: Diagramas, capturas de pantalla o configuraciones extra que complementen la entrega.
